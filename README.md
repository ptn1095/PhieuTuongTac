# Cô Thùy Tin – Kho phiếu bài tập tương tác

Trang web: **https://ptn1095.github.io/PhieuTuongTac/**

Học sinh chọn khối (Khối 3, Khối 5, Khối 9, Đội Tuyển), bấm **Làm bài**, làm xong bấm **Tính điểm** – điểm tự gửi về cho cô.

## Cách thêm phiếu
Danh sách phiếu nằm trong `phieu.json`. Mỗi phiếu là một mục:

```json
{ "khoi": "khoi-3 | khoi-5 | khoi-9 | doi-tuyen", "mon": "Môn – bộ sách", "ten": "Tên phiếu",
  "lop": ["3A4", "3A5"], "ngay": "YYYY-MM-DD", "link": "https://claude.ai/artifact/..." }
```
